# Scripting with Vectors

OpenSearch has powerful scripting support. Scripting allows you to provide custom functionality over.

In OpenSearch, we provide a few different options for scripting with vectors. 

Scripting can be used to execute exact nearest neighbor search or provide more custom scoring on results returned by vector search.

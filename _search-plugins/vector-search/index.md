# Vector search

OpenSearch is a comprehensive search platform that supports a variety of data types, including vectors. OpenSearch vector database functionality is seamlessly integrated with its generic database function.

In OpenSearch, you can generate vector embeddings, store those embeddings in an index, and use them for vector search. OpenSearch provides the flexibility to either generate embeddings using a library of your choice before ingesting them into OpenSearch or automatically generate embeddings within OpenSearch. Once you ingest vectors into an index, you can perform a vector similarity search on the vector space.
